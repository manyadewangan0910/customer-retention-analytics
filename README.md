# E-Commerce SQL Analysis

## 📌 Project Overview

SQL analysis of an e-commerce dataset to understand customer behavior, sales performance, order trends, retention, and product/category performance.

## 📊 Analysis Completed

### 👥 Customer Analysis

* Identified customers' **first purchases** and subsequent orders.
* Calculated **90-day repeat customer retention**.
* Analyzed the **monthly percentage of repeat customers**.
* Identified customers who placed orders in **at least 3 different months**.
* Identified the **customer with the highest number of orders**.
* Calculated the **average number of orders per customer**.
* Identified customers whose **total spending was above the average customer spending**.

### 💰 Sales & Order Analysis

* Identified the **top 3 customers by total spending**.
* Calculated **monthly Average Order Value (AOV)**.
* Identified the month with the **highest AOV**.
* Identified the month with the **highest number of orders**.
* Identified the **product category generating the highest revenue**.
